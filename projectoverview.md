# HomeHive - Project Overview

## 📱 App Scope
**HomeHive** is a comprehensive real estate application designed for both **renters** and **buyers**. 

## 🔐 Authentication Flow
- **Mobile Login**: Users will authenticate using their mobile numbers.
- **OTP Verification**: An OTP (One Time Password) will be sent for verification.
- **Post-Login Navigation**: Upon successful OTP verification, the user will be redirected directly to the **Home Tab Screen**.
